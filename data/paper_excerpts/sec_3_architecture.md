# Doc-to-LoRA §3: Meta-Learning Context Distillation

Source: arXiv:2602.15902 (Charakorn, Cetin, Uesaka, Lange — Sakana AI, 2026)

## 3.1 Learning to Internalize Context with Hypernetworks

In this work, we focus on meta-learning query-independent CD, which allows the internalized parameters θ_c to be used with unseen downstream queries. Thus, the meta-training phase trains a hypernetwork to map a context c to a set of adapter parameters that modify a frozen base model θ, yielding a context-internalized model θ_c = θ + ΔW_c, where ΔW_c = H_φ(c) and H_φ represents a mapping from a raw string to LoRA parameters, parameterized by φ.

The overall meta-training process is similar to the vanilla CD (Eq. 2) with one key distinction: Optimizing a single H_φ that generalizes across many contexts (tasks), rather than optimizing separate ΔW per context. The hypernetwork must be exposed to a vast number of contexts to robustly represent the CD process. Consequently, the meta-training dataset D must include diverse contexts, queries, and responses: D = {c_i, D_{c_i}}_{i=1}^n. Mathematically, we optimize H_φ to minimize the divergence between the context-conditioned teacher and the context-internalized student:

  min_φ E_{(c, D_c)~D} E_{(x,y)~D_c} J(x,y,c),
  J(x,y,c) = KL(p_θ(y | x, c) || p_{θ + H_φ(c)}(y | x))   (Eq. 4)

After training on a large corpus D, the trained hypernetwork should serve as a generic mapping between context information c and corresponding internalized parameters θ_c, generated by a single D2L hypernetwork forward pass. That is, a trained mapping H amortizes both the query generation process and the backpropagation needed by traditional CD.

## 3.2 D2L Architecture

Next, we describe how D2L maps a context string into LoRA matrices. A context c is fed through the frozen target LLM to obtain per-layer token activations Z ∈ R^{L × N × D}, where L is the number of Transformer layers (including the embedding layer), N is the number of context tokens, and D is the hidden size. We denote the activations at depth l by Z_l ∈ R^{N×D}, with Z_0 being the token embeddings. For each transformer layer l ∈ {1, ..., L}, a shared hypernetwork h_φ consumes Z_{l-1} and outputs low-rank LoRA parameters: h_φ(Z_{l-1}) = ΔW_l = B_l A_l. Specifically, each target weight W_l ∈ R^{d_in × d_out} is adapted as:

  W'_l = W_l + α_l B_l A_l;
  A_l ∈ R^{r × d_in},
  B_l ∈ R^{d_out × r}    (Eq. 5)

where r is the rank and α_l is a learnable per-layer scalar.

### Perceiver-Based Hypernetwork

We structure the hypernetwork h_φ as a Perceiver-style cross-attention module (Jaegle et al., 2021) that maps variable-length inputs (Z_{l-1}) to a fixed number of latent queries (the LoRA rank). For each layer l, we use r learnable, input-independent latent queries Q_m ∈ R^{r × d_q}. Cross-attending Q_m to Z_{l-1} yields r latent vectors:

  U_l = XAttn(Q_m, K(Z_{l-1}), V(Z_{l-1})) ∈ R^{r × d_q}   (Eq. 6)

where K(·) and V(·) are linear projections. Two per-layer output heads then produce the LoRA matrices by mapping each latent to a row of A_l and a column of B_l. Overall, the mapping from a context string to LoRA matrices, H_φ, given context c and its token activations Z, can be written as:

  H_φ(c) = ΔW = {ΔW_l}_{l=1...L},
  ΔW_l = B_l A_l = h_φ(Z_{l-1})    (Eq. 7-8)

### Long-Context Composition via Chunking

For long contexts, we partition c into K contiguous chunks {c^{(k)}}_{k=1}^K and process each chunk independently through the hypernetwork, producing per-chunk adapter (A_l^{(k)}, B_l^{(k)}). We then combine chunks by concatenating along the rank dimension:

  A_l = [A_l^{(1)}; ...; A_l^{(K)}],
  B_l = [B_l^{(1)} ... B_l^{(K)}]    (Eq. 9)

resulting in LoRA matrices with the total rank r·K. This composition allows D2L to integrate information across many chunks without changing the output shape of the hypernetwork.
